🚀 Laboratorio VPS: WireGuard + Docker + SSH

Arquitectura segura para 20 estudiantes en 5 grupos

🧠 Orden Correcto

1. Instalar Docker
2. Crear usuarios + contenedores + ForceCommand
3. Instalar WireGuard
4. Crear clientes VPN
5. Restringir SSH
6. Probar

⚙️ 1. Preparar VPS

sudo apt update && sudo apt upgrade -y
sudo apt install -y docker.io ufw curl nano
sudo systemctl enable --now docker

👥 2. Usuarios + Docker

sudo chmod +x crear_laboratorio.sh
sudo ./crear_laboratorio.sh

✔ 5 contenedores
✔ 20 usuarios
✔ ForceCommand activo

🔐 3. Instalar WireGuard

wget -O wireguard.sh https://get.vpnsetup.net/wg
sudo bash wireguard.sh

🌐 4. Crear clientes VPN

sudo bash wireguard.sh → Add a new client

🧪 6. Probar conexión

ssh estudiante1@10.66.66.1

Match User estudiante4

✔ Entra directo al contenedor

❌ Por qué NO usar grupos Linux

1. No controlan Docker

usermod -aG grupo1 estudiante1

❌ No decide contenedor
❌ No restringe comandos
❌ No controla Docker

2. No controlan SSH

ssh estudiante1@servidor
→ /home/estudiante1

❌ Acceso al sistema
❌ Movimiento libre
❌ Riesgo de escalación

3. Sin aislamiento

❌ Todos en el mismo sistema

✔ Por qué este enfoque es mejor

Control total

Usuario → SSH → Contenedor directo

✔ Sin acceso al host
✔ Aislamiento real

Seguridad

Grupos Linux = 🔴 Baja
Docker + SSH = 🟢 Alta

Privilegios

→ 🔥 casi root

✔ Evitado en este sistema
